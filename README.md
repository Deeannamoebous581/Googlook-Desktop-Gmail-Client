## 🔑 How to Use the Client

Once you launch the app, you will see a sign-in screen. Because this app connects directly to Gmail services, it follows standard Google security protocols.

### Adding your first account
When the application opens, select the "Add Account" button. A secure web window will appear. Input your Gmail address and password here. This process creates a secure link between your computer and your email provider. 

### Managing multiple accounts
You can add more than one email address. Select the "Settings" gear icon in the top corner to find the "Add Another Account" option. Each account maintains its own inbox folder. You can toggle between these accounts using the sidebar menu on the left side of the screen.

### Staying connected
Check the system tray in the bottom right corner of your Windows taskbar. You will see the Googlook icon when the app runs in the background. Right-click this icon to quit the program or open the main window quickly.

## 🛠 Troubleshooting Common Issues

Most users experience smooth operation. If you encounter problems, refer to these common solutions:

* App does not launch: Check your Windows updates. Ensure you have the latest drivers for your display.
* Cannot receive notifications: Click the Windows Start menu, navigate to Settings, then System, then Notifications. Ensure Googlook has permission to send alerts.
* Account sign-in loops: Sometimes security settings in your Google account prevent third-party access. Log in to your Gmail through a web browser and check your account security settings to allow "Less Secure Apps" or grant permission to the desktop client.
* Performance lag: If the app feels slow, close other unused programs in your taskbar. High memory usage from web browsers can sometimes affect performance.

## 🔒 Security and Privacy

Googlook-Desktop-Gmail-Client serves as a bridge between your desktop and Google servers. It does not store your password on your hard drive. Instead, it uses tokens provided by Google to verify your identity. If you ever lose your computer, you can log in to your Google Account security dashboard from any browser to revoke access for "Googlook." This immediately disconnects the app from your email data.
